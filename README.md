Trabajo Práctico de Taller de Programación 2

Estructura del proyecto:

Arone_TP1_TDP2
- web.html (Formulario)
- styless.css (Interfaz)
- package.json (Node)
- server.js (Servidor)
- app.js (DOM)

Endpoints de la API REST:

- GET - /api/conceptos - Obtener la lista de todos los conceptos
- GET - /api/conceptos/:id - Obtener un concepto por id
- POST - /api/conceptos - Crear un nuevo concepto
- DELETE - /api/conceptos - Eliminar todos los conceptos
- DELETE - /api/conceptos/:id - Eliminar un concepto por id
